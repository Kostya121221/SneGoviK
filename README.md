# ☃️ SneGoviK

Проект для расчётно-графической работы (РГЗ) по дисциплине **«Программирование»**.

Репозиторий содержит приложение для работы с алгоритмами криптографии. Сборка проекта осуществляется с помощью **CMake** и использует компилируемые динамические библиотеки (`.so` ).

---

## 📂 Структура проекта

* `main.cpp` — основная точка входа в программу.
* `ciphers/` — заголовочные файлы для криптографических алгоритмов.
* `scripts/` — вспомогательные скрипты ввода-вывода.

---

## 🚀 Сборка исполняемого файла на Linux

```bash
mkdir build && cd build && cmake .. && make && ./main_app
```
После этого автоматически создадуться динамические библиотеки и запуститься исполняемый файл
