# SneGoviK
Проект для расчётно-графической работы по дисциплине:"Программирование"

---

##Сборка исполняемого файла на linux
###1. Очищаем старый кэш (если он был)
rm -rf build

###2. Создаем папку сборки и заходим в нее
mkdir build && cd build

### 3. Конфигурируем и собираем
cmake ..
make

### 4. Запуск готовой программы
./main_app
---

сборка исполняемого файла на win
### 1. Очищаем старый кэш (если он был)
if (Test-Path build) { Remove-Item -Recurse -Force build }

### 2. Создаем папку сборки и заходим в нее
mkdir build
cd build

### 3. Конфигурируем проект
cmake ..

### 4. Компилируем кроссплатформенной командой
cmake --build . --config Release

### 5. Запуск готовой программы 
.\Release\main_app.exe
