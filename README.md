# ☃️ SneGoviK

Проект для расчётно-графической работы (РГЗ) по дисциплине **«Программирование»**.

Репозиторий содержит приложение для работы с алгоритмами криптографии. Сборка проекта осуществляется с помощью **CMake** и использует готовые скомпилированные динамические библиотеки (`.so` ).

---

## 📂 Структура проекта

* `main.cpp` — основная точка входа в программу.
* `ciphers/` — заголовочные файлы для криптографических алгоритмов.
* `scripts/` — вспомогательные скрипты ввода-вывода.
* `lib/` — готовые бинарные файлы библиотек (`.so` для Linux).

---
